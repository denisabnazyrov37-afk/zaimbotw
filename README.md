# Telegram Loan Bot — Render-ready

## Быстрая настройка

Вам больше НЕ нужно добавлять `BOT_TOKEN` и `ADMIN_IDS` в Render Environment Variables.

Откройте `bot.py` и найдите:

```python
BOT_TOKEN = "ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER"
ADMIN_IDS = {"ВСТАВЬ_СЮДА_TELEGRAM_ID_АДМИНА"}
```

Замените значения, например:

```python
BOT_TOKEN = "1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxx"
ADMIN_IDS = {"123456789"}
```

Если администраторов несколько:

```python
ADMIN_IDS = {"123456789", "987654321"}
```

**Никогда не публикуйте такой `bot.py` в публичном GitHub после вставки настоящего токена.**
Токен дает доступ к управлению ботом. Для реального проекта безопаснее использовать секреты Render; Render официально рекомендует environment variables именно для защиты секретных учетных данных.

## Render

Build Command:
```bash
pip install -r requirements.txt
```

Start Command:
```bash
python bot.py
```

Environment Variables для токена/ID больше не нужны.

## Админ

В Telegram администратор отправляет:

`/admin`

Для заявки №1:

`/approve_1`
`/reject_1`
`/paid_1`
`/case_1`

## Важно

В проекте обрабатываются паспортные данные и фотографии. Для разработки используйте тестовые данные. Перед реальной эксплуатацией нужны защищенное хранение, контроль доступа, политика удаления, необходимые согласия и юридическая проверка модели займа.

Техническая выписка `/case_ID` не является гарантией юридического взыскания.
