# Loan Telegram Bot

Готовый каркас Telegram-бота для приема заявок на займ.

## Возможности

- `/start`
- 📝 Подать заявку
- Пошаговая анкета:
  - ФИО
  - телефон
  - дата рождения
  - адрес проживания
  - паспортные данные
  - адрес регистрации
  - сумма займа
  - срок
  - банк и реквизиты
  - фото паспорта
  - фото регистрации
  - селфи с паспортом
- отдельное подтверждение персональных данных
- финальное подтверждение заявки
- просмотр своих заявок
- статусы: рассмотрение / одобрено / отказано / выдано
- автоматический PDF-проект договора
- `/contract_ID`
- `/admin`
- `/approve_ID`
- `/reject_ID`
- `/paid_ID`
- `/case_ID`
- уведомление конкретному сотруднику о новой заявке
- кнопки администратора для изменения статуса

## Стек

- Python 3.11+
- aiogram 3
- SQLAlchemy async
- PostgreSQL
- Redis не обязателен
- ReportLab для PDF

## Запуск

1. Создайте Telegram-бота через BotFather и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Заполните переменные.
4. Запустите PostgreSQL.
5. Установите зависимости:

```bash
pip install -r requirements.txt
```

6. Запустите:

```bash
python -m app
```

## Важная настройка уведомлений

`NOTIFY_CHAT_ID` — Telegram chat ID конкретного пользователя/сотрудника, которому бот отправляет уведомление о новой заявке.

`ADMIN_IDS` — Telegram user IDs администраторов через запятую.

Например:

```env
NOTIFY_CHAT_ID=123456789
ADMIN_IDS=123456789,987654321
```

Для получения ID можно временно использовать собственного служебного бота/команду или посмотреть ID через Telegram-инструмент.

## Безопасность

Здесь обрабатываются паспортные данные, фотографии документов и селфи. Перед промышленным запуском необходимо:

- использовать HTTPS/TLS и защищенную БД;
- ограничить доступ администраторов;
- хранить секреты только в переменных окружения/secret manager;
- настроить шифрование файлов/объектного хранилища;
- установить сроки хранения и удаления документов;
- вести журнал доступа;
- проверить требования GDPR/локального законодательства;
- получить юридически корректное согласие на обработку персональных данных;
- не пересылать документы в обычные чаты без необходимости.

PDF в этом проекте является проектом договора и не заменяет юридическую проверку.
